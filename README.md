## ゲーム公開の引き継ぎ

- 新しいゲームをVercelで公開するときは、最初にゲーム専用のGitHubリポジトリと対象のVercelプロジェクトを接続する。既存ゲームは現在のプロジェクトと公開URLを引き継ぐ。
- 通常更新はGitHubの `main` に変更を反映し、対象コミットのVercelステータスを確認する。その後、固定の公開URLで版表示と変更した機能を実際に操作する。スマホ幅のChromiumとiPhone実機のSafariは検証結果を区別する。
- Ver.0.61の移行時、本人は管理画面にログインできたが、ChatGPTのVercel連携ではチーム内のプロジェクト一覧が0件、対象取得が404、権限照会が403だった。403の理由は、その連携アプリに対象プロジェクトへのアクセス権がないこと。404単独で原因を決めず、公開URL・本人のアクセス・連携の権限を確認する。
- 当時はクラウドブラウザに保存済みZIPを直接渡せなかった。GitHub ActionsでZIPを転送・検証し、展開したゲームを `main` に配置して公開できた。通常更新にはZIPの再添付もリリースの作成も不要。再ログインや手動アップロードを利用者に頼む前に、GitHub経由で進める。TinyFishは使わない。
